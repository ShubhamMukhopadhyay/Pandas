# 🐼 Pandas Learning Repository

A hands-on learning repository focused on **Python Pandas** for data manipulation, cleaning, analysis, and exploration.

This repository contains Jupyter Notebooks, datasets, and practical examples covering important Pandas concepts from the basics to more advanced data-analysis operations.

---

## 📌 About

This repository is part of my journey of learning **Data Analysis with Python and Pandas**.

The notebooks contain practical implementations and examples of concepts such as:

- Creating and working with Series
- DataFrames
- Data cleaning and handling missing data
- Merging, joining, and concatenating datasets
- GroupBy and aggregation
- Pivot tables
- DataFrame operations
- Feature extraction
- Working with CSV datasets
- Data filtering and manipulation

The goal is to understand Pandas concepts through **hands-on coding and real datasets** rather than only studying theory.

---

## 📚 Topics Covered

### 1. Series
Introduction to Pandas Series and basic operations.

### 2. DataFrames
Creating, accessing, modifying, filtering, and analyzing DataFrames.

### 3. Missing Data
Handling missing values using techniques such as:

- `isnull()`
- `notnull()`
- `dropna()`
- `fillna()`

### 4. Merging, Joining & Concatenation
Combining multiple datasets using:

- `merge()`
- `join()`
- `concat()`

### 5. GroupBy & Aggregation
Grouping and summarizing data using:

- `groupby()`
- `sum()`
- `mean()`
- `min()`
- `max()`
- `count()`
- `agg()`

### 6. Pivot Tables
Creating summarized tables using Pandas `pivot_table()`.

### 7. DataFrame Operations
Performing different operations on rows, columns, and datasets.

### 8. Feature Extraction
Extracting useful information and features from existing data.
